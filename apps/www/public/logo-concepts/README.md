# Spore Logo Concepts

Black-and-white vector concept set for early direction review.

## Core Spore

- `core-spore-orbit.svg`: centered core with four controlled spores; closest to "gravity center".
- `core-spore-branch.svg`: asymmetric organic branching; strongest growth feeling.
- `core-spore-signal.svg`: more directional and dynamic; reads like propagation or collaboration.
- `core-spore-gateway.svg`: geometric petals around a nucleus; most system-oriented.

## S-Glyph

- `s-glyph-flow.svg`: soft, thick S-curve with three nuclei; most brand-like.
- `s-glyph-orbit.svg`: clearer hidden S with outer spores; balances symbol and language mark.

## Review Lens

- Small-size legibility
- Distinctiveness from Rust / Elixir / Zig
- Favicon compatibility
- Whether it feels like "organic system" instead of "bio startup"

## Rasterize For SSH Review

From `spore-lang.dev/`:

```bash
pnpm logos:rasterize
```

Outputs PNG previews to `apps/www/public/logo-concepts/png/` in `64`, `256`, and `512` sizes.
